# Learning Modern C (C23)

I already have a solid foundation in C, but much of my knowledge comes from an older university curriculum. It did not cover modern C standards or explore recent compiler toolchains such as Clang and the latest versions of GCC in depth. As a result, I have gaps in my understanding of the language and do not always feel confident choosing and using the right development tools for my projects.

## Goals

- Revisit C systematically, starting with the fundamentals.
- Learn the features introduced by modern C standards, with an emphasis on C23.
- Gain a deeper understanding of modern compilers and development tools.
- Strengthen my practical C programming skills.
- Prepare more effectively for technical interviews.

## Learning approach

I am working through [*Modern C, Third Edition*](https://gustedt.gitlabpages.inria.fr/modern-c/) by Jens Gustedt, which covers the C23 standard. I will follow the structure of the book as I organize my notes in this repository.
